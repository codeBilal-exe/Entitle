# Walkthrough

Record the real product. Do not use a premade citizen or a notice written only for a demo.

## Before you start

1. Start the app. n8n can be off.
2. Sign up as a new citizen. Leave the profile empty on camera, then fill in age and education yourself.
3. Sign in as staff with the password from the environment. The sign-in page does not list that account.

## What to show

| Time | Screen | What the viewer should see |
|---|---|---|
| 0:00–0:20 | Sign in and sign up | Empty form. The line that a person and a model work together. The three human stops. |
| 0:20–0:45 | Empty profile, then save | Nothing exists until the citizen types it. Home shows programmes and official links. |
| 0:45–1:10 | Staff desk | Sources, including any that are unreachable. Check sources now. |
| 1:10–1:40 | Draft | Quote check. A person approves or rejects. The model did not decide. |
| 1:40–2:05 | Reviews | Name and eligibility change only. Release or hold. |
| 2:05–2:30 | Citizen alerts and packet | Unread count. The alert says what changed and the next step. The citizen approves the exact packet. |

If a source cannot be read, say so. Do not type in a quota or an age band that was not on the page.

## After

The activity log (admin) should show the human decisions. Sending stays off unless mail is configured and an admin has left the switch on.
